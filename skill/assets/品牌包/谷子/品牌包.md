# 品牌包：谷子

一套锁死项 = 一个品牌。子 Skill 只读本目录，不改。要改先改表，再重跑受影响的那一态。

| 表 | 管什么 | 谁读 |
|---|---|---|
| `风格.md` | 页图视觉、Logo | `min-visual` |
| `模板/` | 超云 003 / 008 / 038，封面四选一 | `min-visual` |
| `音色.md` | TTS 供应商、voice_id、语速 | `min-voice` |
| `字幕.md` | 字体、字号、位置、切句 | `min-voice` |
| `配乐.md` | 底乐、翻页音效、压低规则 | `min-bgm` 选曲收曲，`min-video` 出片 |

脚本从这些表里读的字段（改表时保持行名不变）：

| 表 | 行名 | 脚本用途 |
|---|---|---|
| `音色.md` | `voice_id` | `gen_pages_vo.py --brand` |
| `字幕.md` | `字号` | `build_ass.py --brand` |
| `配乐.md` | `曲库`、`底乐`、`翻页` | `build_video.py --brand` 按内容稿选曲，缺省底乐只作平手回退 |
| `风格.md` | `Logo` | `stamp_pages.py --brand` |

素材根目录见 `config/素材库.md`。
