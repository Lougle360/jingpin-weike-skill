# 字幕

字幕是听的人的栏，不是把 PPT 再抄一遍。

| 字段 | 值 |
|---|---|
| 形态 | 电影底栏。不要大号金句、不要朱砂强调 |
| 位置 | 正下方居中，不挡主标题。不铺底色条、不发光 |
| 字体 | Microsoft YaHei |
| 字号 | `54` |
| 字色 | 暖白 `#F6EFE2` |
| 描边 | 黑，3 |
| 一幕一行 | 同一时刻只有一行，不许 `\N` |
| 每行 | 约 12～16 个汉字，超了按口气拆下一条，不许把词切断 |
| 切句 | 按口气断：句号、问号处切；长句在逗号、顿号、冒号处拆。不要按字数硬切 |
| 标点 | 顿号、逗号、冒号、分号保留，避免「走、路」粘成「走路」。句号、引号、书名号、括号不上屏。舞台提示（停顿）不上屏。真问才留问号 |
| 禁用 | 组件 ID、旧栏目名、「第 N 页」、讲师名 |

交付 `字幕轨.ass`，样式名 `Course`。
