# 总课程导航

Agent 检索本库的第一入口。写方案和内容稿草稿时不要打开；草稿写完后由 `min-review` 从这里进来找组件。

## 这个库讲什么

面向学龄期孩子的家长，解决日常亲子互动里反复出现的具体问题：怎么提要求、怎么接住情绪、怎么建立习惯、什么时候该收手。

不讲什么见 [kb-profile.yaml](../kb-profile.yaml) 的 `excluded_topics`，以及 [14-边界](../14-边界/边界-家庭教育与心理干预的分界.md)。

## 怎么找组件

按问题类型进：

| 你要查 | 去哪 |
|---|---|
| 某个说法是什么意思 | [02-概念](../02-概念/) |
| 为什么会出现这个现象 | [03-原理](../03-原理/) |
| 家长通常怎么想错 | [05-误区](../05-误区/) |
| 具体该怎么做 | [08-规则](../08-规则/) |
| 有没有例子 | [10-案例](../10-案例/) |
| 这事该不该我管 | [14-边界](../14-边界/) |

全部组件一览见 [组件总表](组件总表.md)。

## 学习路径

新手家长建议顺序：先看概念建立共同语言，再看误区排掉常见错误认识，然后看原理理解机制，最后落到规则和案例。边界任何时候都要先过一遍。
