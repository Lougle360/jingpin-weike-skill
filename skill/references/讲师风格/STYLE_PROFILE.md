# 谷子老师口播风格档案

语料来源：`《五福系统课》-D3新-逐字稿.md`，共 75 页，其中 71 页含备注逐字稿。

这份材料是“口语转写＋课程脚本＋舞台提示＋营销文案”的混合稿，不是纯净录音转写。第 39—40 页、第 53 与 71 页、第 68—70 页存在重复；第 26、52、64 页含编写占位；第 72—75 页无有效逐字稿。重复、占位和页面编排不进入声纹。

## 一句话声音

像一位懂国学、见过真实案例、重视家庭责任的老师，在直播间面对面带着普通人把复杂问题想明白；不是写文章，也不是念教案。

## 稳定特征

### 问着讲

老师很少连续下定义，常用“为什么？”“什么意思？”“会怎么样？”“对不对？”推动下一句。问句不是装饰，后面很快会给回答、例子或判断。

### 抽象概念必须落地

五行、六亲十神、财库、大运流年等术语出现后，会被翻成：

- 谁在托举、约束或分流你
- 钱怎样进来、留下或漏走
- 家里遇到风险能不能接住
- 什么时候该冲、该守

### 用画面代替定义堆积

高频比喻领域：

- 水管、口袋、杯子、容器
- 跑车、卡车、道路、高速公路
- 季节、天气、雨伞、衣服
- 炒菜、食材、吃饭
- 身体、食物、能量循环

比喻后必须回到当前知识点，不能只追求金句。

### 从个人问题落到家庭责任

老师谈财富时，真正强调的是家庭底气、父母养老、孩子教育、重大风险和责任承接。情绪方向是“更稳、更有选择”，不是“一夜暴富”。

### 现场感

常见动作：

- 让听众回忆前课
- 让听众二选一、三选一
- 让听众判断自己属于哪种情况
- 让听众复述关键词
- 根据评论区假想反馈继续讲

互动必须与知识点有关。

## 语言节奏

- 句长中位数约 13 字，平均约 17 字。
- 大量短句用于回答、转折和落锤。
- 长句主要出现在案例叙述、情绪铺陈和课程说明。
- 教学解释偏短呼吸；情绪升高或介绍课程时，会出现较长的并列句。不要把老师模仿成全程整齐短句。
- 常先铺一段，再用“不是。”“不行。”“这就叫……”收住。
- 允许重复关键词，避免同义词轮换造成书面腔。
- 连续两句长句后，应出现短句或提问。

## 常用推进方式

### 认知转折

`大家原来怎么理解 → 追问 → 不是表面答案 → 给出新的理解 → 举例`

### 三层拆解

`先说整体 → 拆成两到三个具体问题 → 分别解释 → 汇总成一句可记的话`

三层拆解是老师习惯，但不能所有模块都机械使用。

### 案例证明

`有一个具体的人 → 他遇到什么困境 → 为什么会这样 → 老师怎样判断 → 做了什么调整 → 结果或提醒`

### 情绪承接

`你以为自己担心钱 → 其实怕家庭有事接不住 → 这种担心很正常 → 需要的是系统和方法`

不得把这种结构套到所有痛点上，也不要替听众作过度心理诊断。

## 场景模式

### 开场与复盘

先确认到场和坚持，再回顾上一课；用简单问题让听众开口，最后引出当天主题。

### 知识讲解

问题开场，下定义，翻译成白话，放进生活画面，回到听众自身，再用一次互动确认。

### 案例故事

人物和处境必须具体。先让听众看到“为什么困惑”，再解释规律。结果不是炫耀，而是证明选择方式发生变化。

### 情绪共鸣

先说真实压力，再追问压力背后的家庭责任；表达理解后必须返回判断或方法，不能长时间只煽情。

### 课程转化

从前文问题自然过渡到“为什么做这门课”；依次说明现场会做什么、为什么要线下、人数为什么受限、价格福利是什么。所有信息必须真实。

## 可用口头句式

开题：

- “那我们先搞清楚一件事。”
- “大家想过没有？”
- “我先问大家一个问题。”
- “你更像哪一种？”

解释：

- “什么意思？”
- “我给大家一个画面。”
- “我给你们打个比方。”
- “我再拆开给你们听一遍。”
- “你把这个听懂了，后面就明白了。”

转场：

- “刚才说了……”
- “讲到这里……”
- “那接下来……”
- “但问题来了。”

确认：

- “对不对？”
- “是不是？”
- “大家听懂了吗？”
- “你们看，一讲到这里，是不是就清楚了？”

落锤：

- “所以你们记住一句话。”
- “这就叫……”
- “不是没机会，是没接住。”

最后一类属于强句式，只能在确有认知转折时使用。

“所以”是高频核心导航词；“说白了”在当前语料中只出现少量，不应伪造成每段必说的口癖。

## 不应模仿

- 原逐字稿中的错别字、病句和重复粘贴
- `/`、`//` 等转录停顿符号
- 未核实的案例、数字、八字判断和机构背书
- 为了像口语故意写得语法混乱
- 把每段都写成“不是……而是……”
- 每一页都安排“扣 1”“打在评论区”
- 把“五年／六年”等原稿内部冲突擅自统一成某个版本

## 初版置信边界

这份档案只来自一堂课程，能稳定描述“直播课与课程转化”风格，暂时不能代表老师在短视频、私域文字、正式文章中的全部表达。新增场景应使用对应场景的真实样本继续校准。
