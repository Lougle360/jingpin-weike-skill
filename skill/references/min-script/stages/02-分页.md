# 02 分页

入：整篇口播。  
出：`内容稿.md` 完整版。停：`Gate-S2稿关.md`。

## 怎么切

- 页数和页序按已过关方案的「预计成品」「内容稿大纲」。一行一页。合法页数 5～12。
- 每页口播约 100～220 字。并列项同页时可略长。练习页含停顿时，口播可以更短，总字数按时长扣停顿。
- 段落自然断口就是页界。不为凑页数拆一句。同一讲法的并列项（如形/气/声）可同页。
- 最后一页收束：要点回顾或下一步，不要另开边界页。
- 大纲和自然断口冲突、需要增删页：回 S1 改方案，不在 S2 偷改。

## 每页三块

```markdown
## 第03页｜怎么看：形、气、声

- 页任务：把「有没有煞」拆成看得见、感觉得到、听得见的三项。

### 上屏字

- 先看形、气、声

### 口播

你先不要问有没有煞。先看这个位置上，形、气、声各有什么干扰……
```

- **页任务**：给出图和配音看的提示，不录音、不上屏。
- **上屏字**：页图能画的字。只准是本页口播里已经出现的场面或原句，一般 1～3 条，每条 ≤ 16 字。不准栏目名、不准「第 N 页」。
- **口播**：逐字念的正文。一段，不要空行分段。

## 自动出题

全文和分页完成后填写「三句」里的标题：

- 4～16 字，写本课最后成立的结论；可以直接用课名。
- 不拿待反驳的错误观点当标题，即使加问号也不行。
- 第 01 页第一条上屏字原样使用标题；标题可以不逐字念出。
- 这是 S2 内部质量项，不增加人的把关环节。

## 收尾

1. 文头「状态」写 `待审`。
2. 按 `Skills/min-review/SKILL.md` 和 `Skills/min-review/RULES.md`（审校器 Prompt V1.1）校准 `内容稿.md`。材料B是内容稿。简报写到 `10-内容稿/知识校准简报-正稿.md`。
3. 跑：

```text
python Skills/min-review/scripts/qa_review.py projects/<课名>/10-内容稿/知识校准简报-正稿.md
python Skills/min-script/scripts/qa_script.py projects/<课名>/10-内容稿/内容稿.md
```

4. 按 `templates/Gate-S2稿关.md` 写 `projects/<课名>/Gate-S2稿关.md`，请人看 `内容稿.md`。聊天不贴口播。人点头后文头「状态」改 `已过`，文件冻结。稿关点头后允许出图并生成待审口播稿；口播稿点头后才允许付费出声。
