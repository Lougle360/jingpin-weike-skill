# 01 脊骨与口播

入：已过方案关的 `方案.md`。  
出：`内容稿.md` 的「三句」「秒数预算」和一整篇口播（先不分页）。不停。

方案关不是 `approved`：停，不写。  
方案结论不是「建议做」：停，回 S1。

## 从方案抄

- 课程目标：写入文头「课程目标」字段。
- 叙事：抄方案「正序」或「体验先导」。体验先导可先观察再解释，不要为了五问式把能念的稿切开重排。
- 停顿：抄方案「停顿秒数」，写入文头「停顿」。字数按时长扣停顿计算。
- 不讲：用方案红线、免责和不讲范围。
- 目标字数、时长、页数：用方案「预计成品」。
- 内容顺序：用方案「内容稿大纲」。一行对应一页，不增加新论点。
- 骨架：用方案「选定结构」，按该结构的环节展开口播。不要写「你以为 → 就好比 → 画面 → 复读」。

## 三句先立

1. 标题 4～16 字（可直接用课名，可从方案课程标题收短）
2. 一句话收获（学员学完能带走的那句，可从学习目标收）

## 按结构展开

按方案的字数、时长和大纲写。方案没有明确规格或大纲：停，回 S1，不自行补。

口播顺序必须能对上选定结构，例如：

| 结构 | 口播怎么走 |
|---|---|
| 金字塔 | 认知地基 → 方法 → 情境应用 → 练习收束 |
| FABE | 是什么 → 特别在哪 → 对学员有何用 → 证据/案例 |
| 四段式 | 觉察 → 理解 → 方法 → 练习 |
| 五问式 | 为什么学 → 学什么 → 怎么做 → 现在做 → 复盘 |
| ERTA | 体验 → 反思 → 理论 → 应用 |
| 三幕剧 | 旧世界 → 转折试做 → 新世界与下一步 |

练习必须落在口播里，不要只写在页任务。

## 口播纪律

- 只写能念的字。不写「第 N 页」、不写栏目名、不写「PPT 上写着」。
- 外壳读 `Skills/min-script/口播.md`，每课换壳。
- 红线读 `Skills/min-script/红线.md`，并遵守方案免责：不铁口、不化解承诺、不看病投资辞职离婚。
- 有原句就用原句，没有就不编。
- 上屏不要出现「你以为」「就好比」「其实是」等旧栏目名。

写完进 `02-分页.md`。
