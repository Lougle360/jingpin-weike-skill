# 口播纪律（精品微课）

写 `内容稿.md` 的口播时用这份。不要去读 `vendor/mini-draft`。

## 顺序

跟方案的选定结构和叙事走。正序按环节讲；体验先导可先观察，再解释。

## 能念的字

- 只写老师能念出口的句子。
- 不念「第 N 页」、栏目名、「PPT 上写着」。
- 上屏字除第 01 页标题外，必须能在本页口播里找到。
- 课堂停顿写成「停十五秒」这样的口令，秒数与文头「停顿」一致。

## 外壳

每课换开场和收束，不要套同一句「各位老朋友」。  
称呼用「你 / 大家」，不要「家人们」。  
长句拆短。术语第一次用人话，再出术语。

## 不要写成

- 你以为 → 就好比 → 画面 → 复读
- 饭桌 30 秒出门标准
- 为凑字数加的空话
