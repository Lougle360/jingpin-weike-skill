# 红线

先守通用，命理或居住观察课再加后面一节。

## 通用

- 事实有来源；观点标明是判断；没证据的标【待验证假设】
- 不保证成绩、收入、疗效、关系、命运、房屋吉凶
- 不用最、第一、唯一、100%、包好（老师原句里有这些字，原样引用；禁止的是自己加）
- 不编造案例、数据、名额、截止时间
- 真实案例要有授权，或改到不可识别
- 能当名字记住的短词，必须已经出现在本课知识库、谷子逐字稿，或 `_state.md` 的课程目标里。没有来源就写成整句。检查只问这串字在不在来源里，不另维护禁用词表

## 命理与观察课

- 不当宿命判决书。不讲注定、逃不掉、命中无、包准
- 不用恐惧绑架（不改就散、不改就灾、这里有煞必须化解）
- 术语先翻译成人话
- 不做命运 / 疗效 / 投资 / 婚姻结果承诺
- 不把命理结论写成心理或医疗诊断
- 不铁口断今年必破、必发财；不推销花钱化解、补财库
- 不把风水直接写成环境科学证明；外研文献名不口播、不上屏

不要：「日柱相冲，注定过不到一块儿。」  
要：「这个组合，就是在『谁说了算』上容易顶牛。」
