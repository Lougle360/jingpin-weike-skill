# 课目录约定

一门课一个目录：`projects/<课名>/`。

稿件用「箱子 + 类型 + 文件名」叫。箱子说它在哪，类型说它是什么。

| 箱子 | 意思 |
|---|---|
| 收件箱 | 题目刚进来，还没写 |
| 草稿箱 | 正在写，还没交给人 |
| 待审稿件 | 已经交上来，等人点头 |
| 待发稿件 | 人点过头，可以往下做 |
| 回收站 | 人退回来了，改完还能再交 |
| 垃圾箱 | 扔掉不做 |

| 类型 | 文件 | 人审 |
|---|---|---|
| 新课题目 | `_state.md` 里的课程目标 | 同题已发才请签发确认扔掉 |
| 课程方案 | `10-内容稿/方案.md` | 教研 · 待审 |
| 内容稿草稿 | `10-内容稿/内容稿草稿.md` | 不送审 |
| 内容正稿 | `10-内容稿/内容稿.md` | 教研 · 待审 |
| PPT 大纲 | `20-页图/PPT大纲.md` | 教研 · 待审 |
| 知识库核对简报 | `10-内容稿/知识校准简报-正稿.md` | 不送审 |
| 完整 PPT | `20-页图/pages/`、`PPT.pptx` | 制作 · 待审（逐页看完整 PPT） |
| 口播稿 | `30-口播字幕/口播稿.md` | 制作 · 待审，可在线编辑 |
| 口播成音 | `30-口播字幕/口播.wav` | 后台产物，不设人工审核 |
| 成片 | `40-成片/成片.mp4` | 签发 · 待审 |

```text
projects/<课名>/
├── _state.md
├── Gate-S1方案.md / Gate-S2内容稿.md / Gate-S3-PPT大纲.md
├── Gate-S4-PPT.md / Gate-S4口播稿.md / Gate-S5成片.md
├── 10-内容稿/
│   ├── 方案.md            定位、观点、边界、文章级论述结构；不拆 PPT 页面
│   ├── 内容稿草稿.md      方案通过后由大模型写成；不打开知识库，不送审
│   ├── 内容稿.md          奇门知识库校正后的正稿；过内容稿关后内容层冻结
│   └── 知识校准简报-正稿.md 草稿校正一遍的简报，备查
├── 20-页图/
│   ├── PPT大纲.md         内容母稿的逐页拆分；教研待审
│   ├── 封面候选-1.png … 封面候选-4.png   003浅 / 003深 / 008 / 038
│   ├── 四种封面.md
│   ├── 选定封面.png       Gate-S3封面 请人看四张候选后写入
│   ├── 选定模板.json      锁定超云目录号
│   ├── 页表.md            页号 · 页名 · 页任务 · 上屏字 · 版式 · 字体
│   ├── _prompts/NN.txt    每页提示词
│   ├── pages-raw/         出图原稿，无 Logo
│   ├── 代表页.png         备查预览；人工逐页审核完整 PPT
│   ├── pages/01-<页名>.png … NN-<页名>.png   已叠 Logo
│   └── PPT.pptx           路径写进 Gate-S3，不另问
├── 30-口播字幕/
│   ├── 口播稿.md           S3 由内容正稿转成谷子老师口语；人工审核后成为配音、字幕的唯一文字源
│   ├── _pages_wav/        逐页 wav（不进 git）
│   ├── 口播.wav           试听关请人看（可选听）
│   ├── 每页秒数.json
│   └── 字幕轨.ass
└── 40-成片/
    ├── _assemble/ _audio/ 中间件（不进 git）
    ├── 成片.mp4           看片关请人看
    └── 质检记录.md
```

## 页号规则

- 页号两位数 `01`～`NN`，`pages/` 文件名以页号开头，排序即页序。
- 页数 = 内容稿 `## 第NN页｜` 的个数 = `每页秒数.json` 条数。三处不一致，S5 不跑。

## 冻结规则

- `方案.md` 过关后受众、观点、边界和文章级结构冻结。
- `内容稿.md` 过关后知识、事实、案例和逻辑冻结；它是所有下游内容母稿。
- `PPT大纲.md` 过关后页数、页序、页面任务和上屏字冻结。
- PPT 依赖 `PPT大纲.md`；口播依赖内容稿与 PPT 大纲；配音和字幕只依赖已审核口播稿。
- 封面风格只从品牌包 `模板/` 的 003 / 008 / 038 出。选定前不准出内页。
- 品牌包只读。
