# min-voice　内容母稿 + PPT 大纲 → 口播、配音、字幕

## 三个上游

```text
10-内容稿/方案.md        只读「预计成品」：视频时长、停顿秒数
10-内容稿/内容稿.md      决定讲什么：观点、事实、案例、数字、方法、边界
20-页图/PPT大纲.md       决定怎样分页：页数、页序、页面任务和讲解范围
```

口播稿不得用 PPT 大纲取代内容母稿，也不得脱离 PPT 大纲改变页序。时长和停顿不得另写，必须等于方案。

## 输出

```text
30-口播字幕/口播稿.md
30-口播字幕/_pages_wav/
30-口播字幕/口播.wav
30-口播字幕/每页秒数.json
30-口播字幕/字幕轨.ass
Gate-S4口播稿.md
```

## 第一步：生成待审口播稿

1. 读取方案「预计成品」、内容稿、PPT 大纲、`templates/口播稿.md`、`口播化.md`、`场景化.md` 和谷子声纹档案。
2. 文头时长、停顿按方案填写。严格按 PPT 大纲的页号、页名和页序写逐页口播。方案有课堂停顿的页，口播用 `（停顿）`，文头秒数与方案一致。
3. 每页只讲该页映射到的母稿内容。
4. 允许把书面长句改短、增加自然过渡、提问回答、场景和有限口头句式。
5. 禁止新增观点、事实、数字、案例、方法或结论。
6. 跑 `qa_voice_script.py`。
7. 写 `Gate-S4口播稿.md`，停下等制作人员逐字审核。

## 第二步：通过后生成声音与字幕

1. 人工通过后重新跑口播稿检查。
2. 音色必须使用品牌包登记的豆包声音复刻 V2 近讲干声配置。
3. 逐页生成声音并拼接 `口播.wav`。
4. 写 `每页秒数.json`。
5. 字幕文字只读已配音的那一份口播。时间只用豆包返回的逐字时间，禁止按字数把整页秒数摊开。`每页秒数.json` 必须带 `timing: words` 和每页 `speech_hash`；口播稿或文头停顿变了、而且要念新稿，先重出成音，不能沿用旧字幕。`（停顿）` 处字幕停在上一句，静音长度用成音里的停顿，不估。

```text
python Skills/min-voice/scripts/qa_voice_script.py projects/<课名>
python Skills/min-voice/scripts/gen_pages_vo.py projects/<课名> --brand 谷子 --yes
python Skills/min-voice/scripts/build_ass.py projects/<课名> --brand 谷子
```

## 成音已在、缺逐字时间

客户改过口播稿、稿和成音不是同一套字：先按现在的口播稿重出成音，再写字幕。不要把旧录音贴到新稿上。

口播稿和成音仍是同一套字、只是字幕按字数摊过：不要重配音。把识别到的时间贴到这份口播上，再重出字幕。

```text
python Skills/min-voice/scripts/align_existing_vo.py projects/<课名>
python Skills/min-voice/scripts/build_ass.py projects/<课名> --brand 谷子
```

- 字幕文字只用这份口播。识别听到的字不进字幕。
- 对上的字，用识别给出的起止。
- 听错了、但仍落在同一小段：画面用稿子的字，时间用这一小段的起止，只在这几个字里分。
- 多听的字丢掉。稿子里对不上的字，夹在前后两个已对上的字之间补时间。
- 整页相似度低于 0.82：说明口播稿已经改过，停止对齐，先重出成音，不写时间，不烧成片。
- 以现在的口播稿为准。旧逐字稿只在没有口播稿时才用来对齐。

## 已点头声音标准

基准成音：`projects/奇门盘上，谁是值符这个老大？/30-口播字幕/口播.wav`。后续课程按这个听感执行。

- 场景：面对面的小班讲课，像老师坐在学员面前把复杂问题讲明白。
- 距离：近讲干声，人声在前；不要空旷、遥远或隔着房间的感觉。
- 质感：温厚、自然、清晰、克制；保留真实呼吸和轻微语气变化。
- 语气：问句自然上扬，重点句稍作强调，结论短促落稳。
- 禁止：混响、大厅感、录音棚旁白感、播音腔、故作深沉和短视频主播腔。
- 不准靠刻意降速、压低音高或后期加厚来假装沉稳。
- 合成时只读 `config/品牌包/<品牌>/音色.md` 的已登记模型、音色和合成指令，不得临时改用其他音色顶替。
- 谷子品牌固定使用豆包声音复刻 V2、`model_type=4`；不要改回带录音棚回音的 V3。

试听验收先听裸声，不叠底乐。出现明显空洞、回音、距离感、全程平读或旁白腔，均不通过；先检查音色配置和合成指令，不用配乐掩盖。

## 口播规范

- 页号、页名、页序必须与 PPT 大纲一致。
- 课名、课程目标、学员和不讲必须与内容母稿一致。
- 时长必须等于方案「视频时长」；停顿必须等于方案「停顿秒数」。没有课堂停顿写 0 秒。
- 书面语改口语，但不改原意。不新造专名；页名和「这就叫」后面的短词必须来自知识库、谷子逐字稿或课程目标，没有来源就写成整句。
- 「不是……而是……」每页最多一组。口头禅每一类全课最多一次，缺了不补。
- 超字数只删场景和空话，不靠更短的新词过关；删不动退回方案改时长。
- 不把「N 小时」作业时限、制作说明和免责声明原句写进口播。
- 提问之后必须回答。
- 称呼用“大家、你、你们”，不用“家人们”。
- 不假装收到真实反馈。
- 不写通用主播腔、AI 套话和空泛鸡汤。
- 舞台提示只用 `（停顿）`、`（互动）`、`（讲案例）`。
- 不念“第 N 页”、组件 ID、栏目名和制作说明。
- 机器生成的口播稿，总字数按每分钟 230～260 字控制，并扣除课堂停顿。审核页上手动保存的稿，不卡字数，页数、页名和大纲不一致也通过。保存后口播稿关自动通过。成音和成片按这份稿重出，不沿用旧逐字稿。重新生成后，字数限制恢复。

## 退回边界

- 表达不顺、老师味不对：只改口播稿。
- 时长或停顿与方案不一致：只改口播文头和对应页的 `（停顿）`，不准自己改方案。
- 分页或每页任务不对：退回 PPT 大纲。
- 观点、事实、数字、案例或方法不对：退回内容稿。
- 方案规模（页数/时长/停顿）不对：退回方案关。
- 口播稿通过后再改字：必须重新配音和生成字幕。
