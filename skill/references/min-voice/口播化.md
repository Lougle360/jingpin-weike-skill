# 口播化　转换合同

第 1 层。管「改什么、保什么、怎么往下讲」。

**不管声纹。** 听起来像谁，只读 `.cursor/skills/guzi-teacher-script/` 的 `SKILL.md`、`STYLE_PROFILE.md`、`EXAMPLES.md`、`REVIEW.md`。

两层打架时：保真、页对齐、时长和停顿听方案「预计成品」、字数听文头「时长 − 停顿」；场景化方法听 `场景化.md`；口头禅、称呼、比喻、互动听谷子档案。不要写成亲切成熟的通用主播。不得自己改时长或停顿。

---

## 核心任务

以已冻结的 `内容稿.md` 为内容依据、以已通过的 `PPT大纲.md` 为分页依据、以方案「预计成品」定时长和停顿，写成老师拿到就能念、可在线审核编辑的 `口播稿.md`。

- 主题、核心观点、关键信息、操作步骤必须还在。
- 页号、页名、页序必须与 PPT 大纲一致；每页口播只使用内容稿中对应的观点、事实、案例和方法。
- 文头「时长」「停顿」必须等于方案「视频时长」「停顿秒数」。
- 不为凑字数加空话，也不为了压进字数把人话收成更短的新词。机器写稿时，总字数听文头「时长 − 停顿」，由 `qa_voice_script.py` 卡 230～260 字/分钟。超了先删场景和空话；删不动就退回方案改时长。不要按 1000～1500 字整篇重写。审核页上手动保存的稿，过关不卡字数。
- 不把上屏字硬塞进口播。视觉仍以内容正稿为准。

## 对话感

像在接听众心里可能冒出来的问，不是单向念讲义。

提问之后必须给回答、解释或明确的观察。不要连续追问把人问停。

可以预想合理疑惑。不准假装已经收到真实反馈，禁止：

- 我看到大家都说……
- 我看评论区……
- 各位都在问……

互动只为理解和练习。分类诊断可以用谷子档案里的「扣 1 / 扣 2」；不拿来要点赞、刷屏。

## 整课怎么推进

只对整课用一次，不要每一页都套：

熟悉处境或感受 → 一个好懂的问题 → 例子或画面 → 回应疑惑、保留不同结果 → 一句能记住的话收束。

- 第 1 页：从熟悉处境切入。课程中间不必重写大开场。
- 中间页：只做「问题 → 白话 → 画面 → 落到人」里的一段。
- 末页：要点回顾或下一步，不要另开边界页。

长句拆短。按完整意思分段。舞台提示只用 `（停顿）` `（互动）` `（讲案例）`，不用【】标签，不写「结构优化」「互动环节」。

## 场景化

概念落成现场话时，按 `场景化.md`：具体情境 → 看得见的动作 → 心里话或对话 → 当下卡点 → 原稿观点 → 原有方法。

不是每页走完六步。已经自然的保留。一次做完诊断和改写，不等待人批诊断，不另开人审关。

场景只为听懂当前页的原观点。不借场景换结论、编学员故事、加页或加教学步骤。字数仍听文头「时长 − 停顿」。

## 内容保护

标注为【保留内容】的句子，必须逐字进入对应页口播。

必须原样留下：

- 数字、人名、步骤、填写模板、重要限定
- 「没有变化」「无需调整」等允许空结果的句子

例子可以更生活化，但不能改它要说明的道理。不能把「可能」改成「一定」，不能把一次体验写成普遍规律。

不编案例、数字、履历、命理结论。没有来源写 `[此处待补：……]`。

## 专名

口播不得新造名字，也不得把内容稿里没有来源的专名念出来。页名、「这就叫 / 称为 / 所谓」和「一种是……：」后面的 2～4 字，必须已经出现在本课知识库、谷子逐字稿，或 `_state.md` 的课程目标里。没有的写成整句。`qa_voice_script.py` 只做这个来源核对，不靠发现一个词、追加一个禁用词。

制作说明和作业时限不进口播。不说「退路句」「做对的标志」「N 小时内」。免责说成老师对听众的话，例如「这个人是假设的，不替谁断吉凶」。

正文要能直接念。不要写成标签，例如「看势：」「下判断：」。不要「其一、其二」、不要「本课只建立」「判断权」「收成三句话」「站在某一边」。同样的意思，用课堂上说得完的句子讲完。

## 口头禅（谷子，可用可不用）

通用口水词少堆：其实、就是说、对吧。  
谷子口头禅只用 `STYLE_PROFILE.md`「可用口头句式」里的原句。每一类全课最多一次，缺了不补，不句句挂：

| 类 | 例 |
|---|---|
| 开题 | 那我们先搞清楚一件事。 / 我先问大家一个问题。 / 大家想过没有？ |
| 解释 | 什么意思？ / 我给大家一个画面。 / 我给你们打个比方。 |
| 确认 | 对不对？ / 是不是？ / 大家听懂了吗？ |
| 落锤 | 所以你们记住一句话。 / 这就叫…… |

称呼用「大家／你们」，不用「家人们」「各位亲爱的家人」。

谈钱落到家里接不接得住，用档案里的水管、炒菜、路；不生硬套「种树」「扎根」，不把每课改写成人生劝慰。

## 写完自检（不输出检查过程）

顺口、像课堂、原意还在、没有空泛说教、没有夸大结论、没有写成通用主播。删除口头禅之后，仍应看得出是这位老师在讲。

只写 `30-口播字幕/口播稿.md`。不附原文对照、修改说明或创作分析。
