# min-video　页图 + 口播 + 字幕 + 配乐 → 成片

人只看 `40-成片/成片.mp4`。本 Skill 按 `templates/Gate-S5成片.md` 写关。聊天不交成片、不另问路径。

## 边界

- 只写 `40-成片/` 和 `Gate-S5成片.md`
- 不改页图、口播、字幕文字
- PPT 关和口播稿关都过、成音完成才跑
- 选曲、收曲、校音的原则在 `min-bgm`；本 Skill 只负责合成

## 先读

1. `config/品牌包/<品牌>/配乐.md`
2. `config/素材库.md`
3. `templates/Gate-S5成片.md`
4. 要换曲、收新曲或校音时再读 `Skills/min-bgm/SKILL.md`

## 入 / 出

- 入：`20-页图/pages/*.png`、`30-口播字幕/口播.wav`、`字幕轨.ass`、`每页秒数.json`
- 出：`40-成片/成片.mp4`、`质检记录.md`

## 锁死形态

| 项 | 值 |
|---|---|
| 画幅 | 16:9，1920×1080，30fps |
| 画面 | 整页图铺满，**页内静止**，禁止推镜；只在翻页淡入淡出 |
| 人像 | 不出镜 |
| 声音 | 口播原响度；底乐按下方已点头标准压低；翻页音效钉在切页点 |
| 字幕 | 烧进画面，用 `字幕轨.ass` 原样式 |

要改任何一项：停，改品牌包。

## 已点头标准（口播压过底乐）

样片：`projects/奇门取用神，为什么必须一事一物？/40-成片/成片.mp4`（2026-09-24 点头：字清，箫只垫一层气）。

混音必须跟样片同一套。数字写在 `配乐.md`，由 `mix_vo_bed.py` 执行：

| 项 | 锁定 |
|---|---|
| 口播 | 原响度，`volume=1.0`，不许压、不许响度归一 |
| 茶室箫 / 缺省 | 电平 `0.14`（不要回到 0.23） |
| 闲箫垫 | 电平 `0.15` |
| 侧链 | threshold `0.04`，ratio `6.5`，attack `55`，release `420`，knee `6` |
| 压低混合 | `sidechaincompress` 的 `mix=0.92`（不要回到 0.82） |
| 翻页 | 电平 `0.38`，不进压低链 |

验法：不用开很大声，听清老师每一句；底乐还在，但不盖字。抢话先降电平、再加快 attack，不要抬人声。只换音量：改 `配乐.md` → `--mix-only`。

## 一步出片

```text
python Skills/min-video/scripts/build_video.py projects/<课名> --brand 谷子
```

内部两步：`assemble_vo_slideshow.py`（静图 + 字幕 + 口播）→ `mix_vo_bed.py`（叠底乐 + 翻页音效，侧链压低）。切页点 = `每页秒数.json` 累加。

成片按 `配乐.md` 曲库对内容稿和页图提示词打分选底乐。国学课垫琴箫，不垫二胡、不垫西洋钢琴、不垫自制正弦层。只换音量或压低：改 `配乐.md`，再 `build_video.py --mix-only`。指定某首：`build_video.py --mix-only --bgm 清冷观察`。收新曲、量 LRA、算电平走 `min-bgm`。

## 硬检查

- `pages/` 张数 = `每页秒数.json` 条数（不等不跑）
- 字幕每条的出现时间必须是逐字时间。成音没有逐字时间、口播稿也没改：用现成口播对齐，不要按字数摊。口播稿已改、和成音对不上：先重出成音，再合成。
- 成片时长 = 口播时长 ±0.5 秒
- 视频流 1920×1080；音频立体声 44.1k
- 听三处：开头 10 秒（底乐淡入）、任一切页（翻页可闻）、任一句间空隙（底乐抬起）

## 质检记录

`40-成片/质检记录.md`：时长、页数、底乐、音效、字幕条数、字幕时间（逐字对齐）、看片意见。

## 驳回

| 被点名 | 做 |
|---|---|
| 配乐抢话 / 太小 | 改 `配乐.md` 电平或压低参数 → `--mix-only` |
| 换曲 | 改曲库关键词，或 `--bgm 曲目名` → `--mix-only` |
| 字幕样式 | 回 S3 声音分支改 `字幕.md` → 重出 ass → 全跑 |
| 字幕和口播不同步 | 口播稿没改：`align_existing_vo.py` 对齐逐字时间，重出字幕再全跑。识别只提供时间，不要手改时间。口播稿已改、和成音对不上：先按口播稿重出成音，再全跑 |
| 某页图 | 回 S3 视觉分支重出那页 → 全跑 |
| 口播表达或念错字 | 回 S3 声音分支改口播逐字稿或重出该页音 → 全跑 |

## 禁止

- 推镜、Ken Burns、页内动效
- 改任何文字、图、音
- 不从素材根取音乐，另下或另生成
- 压低到底乐无声；口播被捎带变小
