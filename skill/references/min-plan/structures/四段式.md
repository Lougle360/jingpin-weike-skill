# 四段式

**定义**：觉察 → 理解 → 方法 → 练习。从看见问题到持续能做。

**用户心理**：容易自责；只想学一个能坚持的方法。

**适用**：情绪、关系、习惯、学完就能用的实操课。

## 环节

1. **觉察**：对号入座。典型场景 + 触发点，产出一张自我画像。
2. **理解**：因果链（触发→反应→后果），减少自责、增加可控感。
3. **方法**：1～2 套 SOP（每套 ≤5 步），有错例和演示。
4. **练习**：至少覆盖 1 个真实情境的当堂任务，标建议用时。

## 质检

- 觉察有具体情境，不是空口号
- 方法不超过 2 套
- 练习能核验，不是「回去想想」
