# ERTA

**定义**：体验 Experience → 反思 Reflect → 理论 Theorize → 应用 Apply。先感受，再理解。

**用户心理**：道理都懂、情绪不过关；行动必须来自体验。

**适用**：疗愈、工作坊感、原生家庭、情绪卷入高。

## 环节

1. **体验**：沉浸场景或回忆引导，触发目标情绪，不是逗乐。
2. **反思**：触发—反应—结果，点出 1 个可改变量；不归罪。
3. **理论**：1 个模型（≤3 点），必须映射回刚才的体验；心理与命理要有衔接逻辑。
4. **应用**：一周内可核验的微行为（任务 / 频次 / 证据），禁止恐惧收尾。

## 质检

- 体验真触发，不是只「好玩」
- 理论不超过 3 点，且对回体验
- 行动有时限和证据，不是口号
