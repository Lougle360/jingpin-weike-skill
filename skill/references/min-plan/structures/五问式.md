# 五问式

**定义**：Why → What → How → Do → Reflect。单节微课脚手架，一节带走一个能用的。

**用户心理**：没时间啰嗦；听懂不等于会做。

**适用**：精品微课默认首选；自我探索也可从是什么递进到如何选择。

## 环节

1. **Why**：1 个痛点场面 + 学了能检验什么 + 旧法对比。
2. **What**：只讲 3 个要点 + 1 个关键定义 + 本课不讲什么。
3. **How**：SOP ≤5 步 + 话术/提示 + 常见坑。
4. **Do**：3～10 分钟可完成的任务，有提交口径。
5. **Reflect**：做对了什么 / 卡在哪 / 下一步（48 小时内可执行）。

## 质检

- 开场 1 分钟内点到人话痛点
- How 有错例
- 结尾有下一步 + 可核验动作
