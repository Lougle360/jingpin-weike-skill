# FABE

**定义**：特征 Feature → 优势 Advantage → 利益 Benefit → 证据 Evidence。讲清「是什么、为何更好、你得到什么、凭什么信」。

**用户心理**：怕踩坑、要快速判断值不值得用。

**适用**：介绍一种方法、工具或视角的价值。

## 环节

1. **特征**：3～5 个模块/功能，每条对准 1 个痛点。
2. **优势**：旧法 vs 新法 2～3 点，落到少错/更快/更稳。
3. **利益**：外化成看得见的变化；短长期都要有画面，不做疗效或命运承诺。
4. **证据**：可核验案例、对照、来源；命理只作象征入口，心理学标明证据层级。

## 质检

- 每条 Feature 能找到对应 Benefit
- 至少 1 个可检验的学习结果（不是报名转化 KPI）
- 证据可追溯，禁止编造人数和疗效
