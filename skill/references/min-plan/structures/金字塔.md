# 金字塔

**定义**：从基础认知 → 核心方法 → 进阶应用 → 整合实战，层层搭到能独立用。

**用户心理**：怕太难、跟不上；想看见成长路径。

**适用**：零基础到进阶、概念+方法、知识密度高。

## 环节

1. **基础认知**：统一术语、拆误区、最小知识卡（3～5 点）。学员能复述关键词，知道本课不讲什么。
2. **核心方法**：只教 1 套 SOP（≤5 步），命名、演示、错例纠偏。
3. **进阶应用**：3 类典型情境，学会选招，不背死步骤。
4. **整合实战**：一个能带走的小成品或练习，点出下一步。

## 质检

- 每层目标可用动词衡量
- 方法有名字、步骤不超过 5
- 终章有可核验练习，不是只听
