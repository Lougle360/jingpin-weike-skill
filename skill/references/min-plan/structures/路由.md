# 结构路由

结构未定时必走。先拆意图，再给 6 种结构打分，截前三名给人选。不准凭印象只推 3 种、后三种不打分。

选定结构或「你来定」时：已有评分表就沿用，没有就当场打完再锁最高分。并列按文末拆分序。

## 1. 意图卡

对照课程目标填写，先不看结构。主收获只标一个；次收获可空，不能与主收获相同。

| 项 | 只许填 |
|---|---|
| 学员此刻 | 还没信 / 已经要学 / 卡住要改 |
| 主收获 | 值不值得用 / 能复述一句 / 能做一步 / 改一个行为 / 过一层情绪 / 被故事翻过去 / 搭出知识树 |
| 次收获 | 上列之一，或空 |
| 当堂产出 | 一句话 / 一次观察 / 一个小练习 / 一个小成品 |
| 情绪温度 | 冷静认知 / 轻卷入 / 高卷入 |
| 知识密度 | 一个观点 / 一套方法 / 一层系统 |
| 红线 | 本课不能做什么；没有就写「无额外红线」 |

## 2. 五维打分

每种结构就这 5 维各打 0～5 分，总分 = 五维之和，满分 25。

| 维度 | 表头 | 5 分 |
|---|---|---|
| 带走对齐 | 带走 | 结构的终点正好是主收获 |
| 学员状态 | 状态 | 开场能接住「学员此刻」，不假设他已经会了 |
| 当堂产出 | 产出 | 4～7 分钟里，这个结构的「做一遍」能做完 |
| 情绪温度 | 情绪 | 该冷的冷、该热的热 |
| 密度匹配 | 密度 | 装得下主收获，也不为填环节注水 |

对照各结构文件的「适用 / 用户心理 / 环节」来打，不要给同情分。

## 3. 判断档

| 总分 | 判断 | 能不能进推荐 |
|---|---|---|
| 22～25 | 主推 | 能，可独立撑完整课 |
| 16～21 | 能用 | 能，须在理由里写要改的一处 |
| 10～15 | 能讲 | 不进前三，除非上面不够 3 个 |
| 0～9 | 劝退 | 默认不进前三 |

## 4. 截前三名

1. 六种都写入「适配度评分」，一种不漏。
2. 按总分从高到低排；同分按拆分序：FABE → 五问式 → 四段式 → ERTA → 三幕剧 → 金字塔。
3. 「结构推荐」只写前三名，各 2～3 句：为何匹配、差在哪。理由里带总分。
4. 后三名只留在评分表，不进推荐，判断仍要写。

人指定某一种：即使不是第一，也按人选定写设计，评分表可留在评估备查，但「建议做」页不必再贴。  
人说「你来定」：锁总分最高者（同分走拆分序），再进完整设计。

## 5. 意图到结构的对照（打分锚，不是自动锁死）

| 主收获 | 通常高分 |
|---|---|
| 值不值得用 | FABE |
| 能复述一句 / 能做一步 | 五问式 |
| 改一个行为 | 四段式 |
| 过一层情绪 | ERTA |
| 被故事翻过去 | 三幕剧 |
| 搭出知识树 | 金字塔 |

有次收获时，对应结构可加 1 分到「带走」，但总分仍不得超过 25，且不能因此把劝退抬进主推。
