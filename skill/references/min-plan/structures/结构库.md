# 精品微课结构库

推荐与生成只许用下列 6 种。定义以本目录各结构文件为准，来源是 `CourseDesign/多结构课程设计`。

默认课型：**轻知识 / 速成微课**（10～20 分钟拿一个可核验结果）。未指定课时按此课型选结构。

| 结构 | 环节顺序 | 适用 |
|---|---|---|
| 金字塔 | 基础认知 → 核心方法 → 进阶应用 → 整合实战 | 知识密度高、要从零搭到能用 |
| FABE | 特征 → 优势 → 利益 → 证据 | 讲清一种方法/视角为什么值得用 |
| 四段式 | 觉察 → 理解 → 方法 → 练习 | 学完就能用的行为改变 |
| 五问式 | Why → What → How → Do → Reflect | 单节微课脚手架，快学快用 |
| ERTA | 体验 → 反思 → 理论 → 应用 | 疗愈、情绪卷入、先感受再理解 |
| 三幕剧 | 旧世界 → 转折 → 新世界 | 以故事为主线的叙事课 |

## 怎么推荐

口径见同目录 `路由.md`。结构未定必须先写意图卡，再给 6 种各打 0～5 分（带走 / 状态 / 产出 / 情绪 / 密度），截前三名写入「结构推荐」。后三种也要给分，不准只凭印象推 3 种。

「你来定」锁评分表总分最高者；并列按：FABE → 五问式 → 四段式 → ERTA → 三幕剧 → 金字塔。已指定结构则跳过推荐，直接生成。

## 翻成分页大纲

方案关必须给出 5～12 页的「页表」，一行一页，每行只写这一页做的一件事。内容稿和 PPT 大纲都按这张表写，不能另分一套页。参考与说明不占页。模块多就合并邻近环节；不要超 12 页；练习单独占 1 页。

详细环节、用户反应和质检见同目录各结构文件。
