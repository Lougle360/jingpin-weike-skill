# 可写主题清单

S1 选题时先对这张表，再查以前有没有发过同题。不是课名全集，是**能开题的方向**。对照格式见 `examples/01-1-别被煞吓住/`。写前不打开知识库。

## 库内课（原文点名 / 邻近可翻）

八字知识在 `knowledge/z5fu-bazi`，奇门知识在 `knowledge/yizheng-qimen`。一节课只带走一个可检验目标，只开对应那一套库。

| 方向 | 可写 | 不写 |
|---|---|---|
| 基石 | 干支、十神、六亲、合冲刑害的人话定义 | 从零讲完整教材、排盘软件教程 |
| 旺衰 | 旺衰是观察顺序，不是命运等级 | 今年必发/必破 |
| 格局 | 格局是取用视角，不是身份标签 | 花钱抬格局 |
| 调候 | 调候是环境与寒暖，不是穿衣指令 | 缺火穿红、缺水戴黑 |
| 性格 | 十神倾向怎么觉察，不鉴定人品 | 杀重就是坏人 |
| 事业 | 事业象征与现实选择分开 | 代人辞职、代人择业 |
| 财运 | 财星是来路观察，不是有钱证明 | 投资建议、补财库 |
| 感情 / 六亲 | 关系模式的自我觉察 | 合婚判决、劝离劝分 |
| 运年 | 流年是天气不是结案 | 本命年必须穿红、不宜出门 |
| 神煞 | 神煞是配角，不单独断事 | 见煞必须化解 |
| 误区 | 八字不是宿命论、不是结论书 | 用恐惧纠偏 |
| 奇门符号 | 八门、九星、八神、天干象意的画面记忆 | 一次讲完整盘符号表 |
| 奇门读盘 | 伏吟反吟、空亡、入墓、门迫、击刑的识别 | 铁口吉凶、布局操作 |
| 奇门取用 | 锁宫、取用神、测事五步的观察顺序 | 代人决断、催旺改宅 |
| 奇门排盘 | 阴阳遁、起局步骤的认法 | 补全库里没有的节气用局表 |

内容生产三条链（概念科普 / 误区纠正 / 案例改写）可作选题切口，成片仍走精品微课方案。

## 观察课（话题在库）

库里只有话题入口，课教可观察经验。方案关必须人确认。外研不进口播。

| 方向 | 样例 | 给养只借 |
|---|---|---|
| 居住干扰 | 别被煞吓住：形 / 气 / 声观察一个座位 | 神煞、现实决策边界 |
| 开口边界 | 观察不是药方、结论不是行动指令 | 边界-课程事业解读与现实决策 |

新开观察课：先写清「借哪个库内话题、教哪一个可观察动作」，再判「话题在库」。不准写成邻近可翻。

## 先不要做

健康诊断、投资决策、辞职、离婚、合婚能不能结、化解商品、铁口流年、把命理写成已被科学证实。
