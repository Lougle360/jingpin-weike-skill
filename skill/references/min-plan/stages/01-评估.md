# 01 评估与结构

入：`_state.md` 的 `course_goal`（没有则读 `folk_saying`）、`audience`、`format`、`structure`。  
出：结论。未撞题且结构已定 → 进 `02-方案.md`。未撞题但结构未定 → 按 `templates/待选结构.md` 写，停。同题已发 → 按 `templates/回流.md` 写，停。

写前不打开知识库。缺受众、形式、风格时用默认值继续：受众=零基础成年学员，形式=图文讲义，课型=轻知识/速成微课。开头用一行标注假设，不要因非关键项追问。

## 做

1. 读 `structures/结构库.md`、`structures/路由.md` 和 `可写主题清单.md`。用一句话复述主旨 + 受众 + 预期收获。
2. 查重（口径见 `Skills/min-plan/判库.md`）：只查以前有没有发布过这样的文章或课。看 `projects/`、样例课、人点名的已发清单。不打开 `knowledge/`。
   - 未发过 → `能不能写` 填 `能`。
   - 邻近同题 → `能不能写` 填 `能`，主旨写清新切口。
   - 同题已发 → `能不能写` 填 `停回流`。
3. 同题已发：写回流单并停。人说换切口重做：改目标后本步重跑。
4. 能写且 `_state.md` 的 `structure` 为空、也不是「你来定」：结论「待选结构」。按 `路由.md` 写意图卡，给 6 种打分，截前三名，按 `templates/待选结构.md` 写，**停下等待**。不准抢跑写课程设计。
5. 能写且已指定结构，或人说「你来定」：进 `02-方案.md`。「你来定」先沿用或补打评分表，锁总分最高者（并列按路由拆分序）。知识库留给正文写完后的那一遍核对。

人选定结构：总控写入 `_state.md` 的 `structure`，`stage` 仍是 S1，本 Skill **从评估接着生成设计**。旧的待选页作废。

## 不做

- 写前翻知识库、填给养文件
- 同题已发还出大设计
- 结构未定时抢写模块和大纲
- 自己替人过关
