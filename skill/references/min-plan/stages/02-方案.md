# 02 课程设计

只在评估结论是「建议做」且结构已定时进来。  
出：按 `templates/方案.md` 写全文。本 Skill 按 `templates/Gate-S1方案.md` 写关。停：人直接看 `方案.md`。

评估是待选结构或回流：不要进本文件。

先读选定结构对应的 `structures/<结构>.md` 和 `structures/风格库.md`。红线见本 Skill「内容红线」。

## 做

1. 写「主旨确认」。用了默认值，先标一行假设。
2. 按选定结构写课程设计：标题、引言（300～500 字）、3～5 条「能够 + 动词」学习目标、核心模块、至少 1 个练习（标用时）、小结（100～200 字）、一行免责。
3. 每模块有小标题、讲解、至少 1 个案例或类比。心理与命理要有衔接逻辑，不做生硬并列。术语首次出现用一句白话解释。
4. 定预计成品：完整内容稿字数区间、视频时长 4～7 分钟、停顿秒数（没有写 0）、PPT页数 5～12（只定规模）和计划改编的下游产品。
5. 选定结构表写「叙事」：`正序` 或 `体验先导`。体验先导开场可先观察，但仍须覆盖选定结构的各环节。
6. 只写文章级论述结构，不拆 PPT 页面；PPT 大纲必须等内容母稿通过后再做。
7. 自检：结构一致、有案例和练习、无宿命论/伪科学/恐惧营销、无组件 ID。精品微课不写带走金句，也不出候选卡片。写前不打开知识库。
8. 跑：

```text
python Skills/min-plan/scripts/qa_plan.py projects/<课名>/10-内容稿/方案.md
```

9. `errors=0` 后按 `templates/Gate-S1方案.md` 写 `projects/<课名>/Gate-S1方案.md`。聊天只回 `方案.md` 路径。方案阶段不做知识库核对。停。等人点头。

## 人点头之后（总控回写）

- `structure` 写入已选定结构。
- `S1 方案关 = approved`。
- 总控进 S2，外呼 `min-script`。S2 只把本设计翻译成分页正式稿，不改结构。

## 驳回

| 人说 | 做 |
|---|---|
| 方案不够好 | 改设计、大纲或成品规格。评估能沿用就沿用 |
| 换结构：X | 改 `structure`，按新结构重写设计，评估能沿用就沿用 |
| 换风格：X | 只改文风，不改结构和目标 |
| 重写：某模块 | 只改指定部分 |
| 其实这题不该做 | 回 `01-评估.md`，改走回流 |

## 不做

- 写旧栏目脊骨（你以为 / 就好比 / 饭桌版）
- 写带走金句，或出候选金句让人圈
- 写分页口播（那是 S2）
- S2 擅自改变已过关的内容范围、核心观点或论述结构
- 宣称命理已被科学证实，或用「注定 / 必然 / 一定会」
