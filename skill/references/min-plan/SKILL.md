# min-plan　课程目标 → 课程设计

输入一个**课程目标**，先查以前有没有发过同题，再定结构，没撞题才出课程方案。方案锁定目标用户、核心观点、内容边界、文章级论述结构，以及制作规模（内容稿字数、视频时长、停顿秒数、PPT页数）。方案不拆每一页讲什么。人点头即锁定。精品微课不写带走金句。写前不打开知识库。

同题已发：写回流单。结构未定：写意图卡，给 6 种打分，截前三名；结论「待选结构」，停下等人选，不准抢写模块。

人直接看 `10-内容稿/方案.md`。聊天只回这份文件路径。本 Skill 按 `templates/Gate-S1方案.md` 写关。

选题先看 `可写主题清单.md`。

## 边界

- 只写 `10-内容稿/方案.md` 和 `Gate-S1方案.md`
- 不打开知识库，不调用 `min-review`
- 不写内容稿、页图、口播、成片
- 不读其他子 Skill 的 `SKILL.md`

## 先读

1. `templates/方案.md`（建议做） / `templates/待选结构.md` / `templates/回流.md`
2. `templates/Gate-S1方案.md`
3. `stages/01-评估.md` → 未撞题且结构已定才进 `02-方案.md`
4. `structures/结构库.md`、`structures/路由.md`；选定后再读对应结构文件和 `风格库.md`
5. 写前查重：`判库.md`
6. 黄金案例：`examples/01-1-别被煞吓住/`
7. 可写主题：`可写主题清单.md`

## 两步

| 步 | 做 | 停在 |
|---|---|---|
| 1 | 复述主旨；查以前发过没有；结构未定则写意图卡、六种打分、截前三名 | 同题已发 → 回流单；未定 → 待选结构，停 |
| 2 | 结构已定才写完整方案、内容规模和论述结构 | 直接呈现 `方案.md` |

## 三个结论

| 结论 | 文件 | 人干什么 | 之后 |
|---|---|---|---|
| 建议做 | 完整课程方案 | 审：目标、观点、边界、论述结构、练习，以及时长/停顿/页数规模 | 点头锁定，进 S2 |
| 待选结构 | 主旨 + 意图卡 + 六种评分 + 前三名 | 选一种，或说「你来定」 | 写入 `structure`，S1 重跑。不准出稿 |
| 建议回流 | 短回流单 | 确认停 | 本课停 |

## 人把关什么

| 人说 | 意思 | 重跑 |
|---|---|---|
| 选定结构 / 你来定 | 结构锁定 | S1 接着写设计。待选页作废 |
| 方案不够好 | 定位 / 观点 / 边界 / 论述结构 / 规模不行 | 只改方案。评估能沿用就沿用 |
| 换风格 / 重写某模块 | 局部改 | 只改指定部分 |
| 同题已发 / 不要做 | 回流 | 不出稿 |

人点头「建议做」：`structure` 写入选定结构，`S1 方案关 = approved`。本 Skill 到此结束。  
人选定结构：**不是**方案关通过，`stage` 仍是 S1。

## 内容红线（最高优先级）

- 不做宿命论：「注定 / 必然 / 一定会」一律改成倾向性表述。
- 不宣称命理已被科学证实；心理学标明「有研究支持」还是「象征类比」。
- 不替代医疗或心理诊断；严重困扰引导专业支持。
- 不做恐惧营销；原生家庭不归罪父母。
- 案例匿名或标虚构。
- 完整设计末尾必须有一行免责。
- 能当名字记住的短词，必须已经出现在课程目标、知识库或谷子逐字稿里。没有的写成整句，不要新造。写的时候仍不翻知识库编内容；`qa_plan.py` 负责用来源核对。

## 硬检查（`scripts/qa_plan.py`）

```text
python Skills/min-plan/scripts/qa_plan.py projects/<课名>/10-内容稿/方案.md
```

- 文头结论只能是 `建议做` / `待选结构` / `建议回流`
- 建议做：以前发过没有为 未发过 或 邻近同题；选定六种结构之一；叙事为正序或体验先导；标题、引言、3～5 条「能够」目标、模块、练习、小结、免责；预计内容稿字数、视频时长 4～7 分钟、停顿秒数、PPT页数 5～12、与页数相同的页表，以及下游产品。页表每行只有页码和这一页做的一件事。参考与说明不占页。不准写带走金句
- 待选结构：意图卡齐全；6 种都打分；推荐必须是总分前三；不准写模块、大纲、金句
- 建议回流：同题已发；不准填大纲和金句
- 无组件 ID
- 建议做的方案：专名必须能在知识库、谷子逐字稿或本课课程目标里找到原词。找不到就失败，不追加禁用词

`errors=0` 才交方案关。

## 禁止

- 同题已发还写大设计
- 写前翻知识库
- 结构未定就填模块和完整论述结构
- 建议做却不写停顿秒数、PPT 页数或页表，或页表行数和 PPT页数不一致
- 用旧栏目当骨架（你以为 / 就好比 / 饭桌版）
- 写带走金句，或出 2～4 张金句让人圈
- 只交内部评估表，不交学习目标和论述结构
- 待选或回流后直接出稿
- 把方案贴进聊天代替 Gate
- 方案阶段打开知识库或写校准简报
