# min-outline　内容母稿 → PPT 大纲

输入：

```text
10-内容稿/内容稿.md
10-内容稿/方案.md     只读「预计成品」：PPT页数、视频时长、停顿秒数
20-页图/选定模板.json  若已有，提示词必须写入该风格锁
```

输出：

```text
20-页图/PPT大纲.md
Gate-S3-PPT大纲.md
```

## 核心原则

- 内容稿决定“讲什么”，PPT 大纲只补上屏字、正文和提示词。
- 页数和每一页的任务以方案「页表」为准。没有页表时，才用预计成品里的 PPT页数。不能增页，也不能删页。
- 已有 `20-页图/_prompts/NN.txt` 时：提示词份数须与页表一致才复用；对不上则按页表重写，不得擅自改页数。
- 不增加内容稿中没有的新观点、事实、数字、案例或方法。
- 页名不新造专名。2～4 字的叫法必须已经出现在知识库、谷子逐字稿或课程目标里；没有的写成整句。`qa_outline.py` 用来源核对。
- 一页只承担页表里的那一件事。页表里的练习页单独保留，不要为了省页把两行并成一页。
- 正文要提供足够的页面信息，不能只抄两句口号；从内容稿提炼成可直接排版的一页内容。
- 提示词必须是可直接交给 Image2 的完整中文自然语言提示词，不写版式代号或关键词拼接。
- 风格以品牌包 `config/品牌包/<品牌>/模板/` 和本课 `选定模板.json` 为准，不读国潮 vendor 的 `prompt-assembly.md` 当风格源。
- 四种风格的大标题一律用中文毛笔行楷，不要印刷黑体。次级字可用较小的端正行楷。
- 「画面」写光、材质、物件和整页合成，像高端杂志摄影。不要写宫格线框、流程图箭头、勾选控件或软件图标，也不要自拟另一套目录号或画派。已选定封面时，每一页第一句必须是该风格的锁定句，并写「必须延续选定封面的底色、字体与气质」。
- 方案没有 PPT 页数：停，回方案关补规模，不准自己估 5 页。

## 每页必备

- 页码
- 标题
- 正文
- 提示词

## 流程

1. 读取已通过并冻结的内容稿，以及方案「预计成品」的 PPT 页数。
2. 如课程已有 `_prompts/NN.txt` 且份数等于方案页数，先读取并复用；否则按选定风格锁写完整中文自然语言提示词。未选定封面时不要写死另一套底色或画派。
3. 按方案页数（须在 5～12 页内）填写 `templates/PPT大纲.md`。开场、练习、小结能单独成页的，不要并进别页。
4. 运行硬检查。
5. 写 `Gate-S3-PPT大纲.md`，停下等待教研审核。

```text
python Skills/min-outline/scripts/qa_outline.py projects/<课名>/20-页图/PPT大纲.md
```

通过后页数、页序、标题、正文和提示词冻结。视觉制作与口播稿可以并行开始。
