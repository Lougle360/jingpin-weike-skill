# min-review　知识库校准

**对人说：** 知识校准  
**对 Agent 说：** 按 min-review / 按知识校准

这不是重新创作，也不是改错字。只做一件事：用 `_state.md` 的 `kb_root` 审核内容稿草稿，把和知识库明确不一致的地方改正，写成内容正稿。奇门课的知识库是 `knowledge/yizheng-qimen`。知识库没写到的选题仍然成稿，不要拒稿。

裁决优先级：

```text
我的知识库 > 原课程内容 > 你的通用知识
```

裁决规则（不可改）：

- **A 匹配**：保留
- **B 明确冲突**：按知识库改正文，写入已修正简报
- **C 部分覆盖**：完全不处理、不汇报
- **D 完全无法匹配**：留在正稿，写入待人工审核简报，不因此拒稿
- **库内冲突**：不裁决，写入待审核简报

完整提示词是 [RULES.md](RULES.md)（知识库校准型课程审校器 Prompt V1.1 全文）。执行前必须通读。与本文件冲突时，以 RULES.md 为准。

## 何时被叫

| 调用方 | 材料B | 校正后写入 | 简报 |
|---|---|---|---|
| S2 `min-script` 刚写完草稿 | `10-内容稿/内容稿草稿.md` | `10-内容稿/内容稿.md`（正稿） | `10-内容稿/知识校准简报-正稿.md` |

草稿保留，不要覆盖。全程只走这一遍。方案阶段、待选结构、回流、方案关未过：不要跑。  
稿关已过、正稿已冻结：不要跑，回 S2。  
人说跳过校准：把草稿原文抄入正稿，简报文头写「跳过」，不挡稿关。

## 材料A｜怎么取知识库

不要假装读完整个知识库。本轮「材料A」= 为这一课检索到的组件，只读、不改。

1. 读 `_state.md` 的 `course_goal`、`kb_root`。这一步才打开知识库。奇门课必须校准 `knowledge/yizheng-qimen`，八字课校准 `knowledge/z5fu-bazi`；指错先改再取材料。
2. 先打开该库总索引：八字库看 `01-索引/总课程导航.md`、`组件总表.md`；奇门库看 `导航/初学者.md`、`导航/Agent调用.md`（没有就用库内现有总索引）。
3. 用本课目标、标题、术语搜索，点名 **3～8 个** 相关组件：概念、原理、框架、规则、观点、误区、边界、案例。
4. **只打开点名文件**。记相对路径，不写组件 ID 进学员可见正文。
5. 打不开、对不上、只能联想到另一课：该条按 D 或 C，不准用训练知识补。

检索结果写进简报文头「本轮材料A」，便于人复核你到底看了哪些文件。

## 材料B｜内容稿草稿

就是 `10-内容稿/内容稿草稿.md`。先通读，再按 RULES.md 做四类判断。不要把草稿当成已经校正过的正稿。

## 做

1. 取材料A、材料B。
2. 内部完成 A/B/C/D。犹豫 B 还是 C → 判 C。能挂上相关框架 → 优先 C，不要升成 D。
3. 只改 B。保持原结构、顺序、口播风格、案例位置、篇幅。不把课改成知识库摘抄。
4. 标准定义、固定术语、口诀、明确规则：含义跟库走。其余可按课的口气改写。
5. 把校正后的干净全文写入 `10-内容稿/内容稿.md`。无删除线、无【修改】【错误】【待审核】标签。不要覆盖草稿。知识库没覆盖的内容留在正稿里。
6. 按 [templates/知识校准简报.md](templates/知识校准简报.md) 写简报。无 B 则第二部分写「无」。无 D 且无库内冲突则第三部分写「无」。
7. 跑：

```text
python Skills/min-review/scripts/qa_review.py projects/<课名>/10-内容稿/<简报文件>
```

8. 交回调用方。由 `min-script` 再跑一次 `qa_script.py`。有 ERROR 就只改点名的句子，简报和正稿再各查一次。同一条 ERROR 还在就停。不要自己过关，不要进下一态，不要写 Gate。

## 禁止

- 搜索外网，或用常识覆盖知识库
- 融合其他流派
- 把 C 当 B 改，或把 C 当 D 堆进简报
- 因「库没写全」删除或改弱课程
- 擅自裁决库内冲突
- 把组件 ID、栏目名写进学员可见正文
- 重写整课、另开结构、改页数规格
- 为了过检查把正稿或简报写第三稿，或在文件没改时再跑检查
